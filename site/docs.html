Documentation

financial-calculators is a set of plain functions: financial calculators that return numbers and yearly series, and formatters that turn numbers into text. It has no dependencies and never touches the page.

Install

In a browser, load the minified file; it defines the global FinancialCalculators:

<script src="https://cdn.jsdelivr.net/npm/@wpgenius/financial-calculators@1/dist/financial-calculators.min.js"></script>
<script>
  const { sip, formatCurrency } = FinancialCalculators;
</script>

With a bundler or Node.js 20+:

npm install @wpgenius/financial-calculators
import { sip, formatCurrency } from '@wpgenius/financial-calculators';

Or download financial-calculators.min.js, financial-calculators.js (readable) or financial-calculators.esm.js from the latest release.

Conventions

  • Each calculator takes one object of inputs and returns an object of unrounded numbers. Round and format them when you display them.
  • Rates are % a year: 12 means 12%.
  • years may have fractions; it's rounded to whole months, from one month up to 1,000 years.
  • Inputs may be numbers or numeric strings ('25000'). A missing or non-numeric input throws a TypeError; a negative one, or a duration under a month or over 1,000 years, throws a RangeError. So does a result too large to be a finite number, instead of returning Infinity or NaN.
  • Every result has months and a series: one point at month 0, 12, 24… and a last point at the final month, each with year and month plus the values listed for that calculator.
  • Every calculator also takes an optional startYear (such as 2026). Each series point then gets calendarYear (startYear + year) for chart labels, and goal() also returns targetYear.

sip( inputs )

Systematic investment plan: the same amount invested at the start of every month, compounded monthly.

InputMeaning
monthlyAmountAmount invested each month.
annualRateExpected return, % a year.
yearsDuration in years.

Returns { invested, returns, total, months, series }; series points { year, month, invested, total }.

sip( { monthlyAmount: 25000, annualRate: 12, years: 10 } );
// { invested: 3000000, returns: 2808477.3…, total: 5808477.3…, months: 120, series: [ … 11 points ] }

lumpsum( inputs )

One-time investment at the start.

InputMeaning
amountAmount invested once.
annualRateExpected return, % a year.
yearsDuration in years.
compoundingPerYearOptional: 1 yearly (default), 4 quarterly, 12 monthly.

Returns { invested, returns, total, months, series }; series points { year, month, invested, total }.

lumpsum( { amount: 25000, annualRate: 12, years: 10 } ).total; // 77646.2…

swp( inputs )

Systematic withdrawal plan: a fixed amount is withdrawn at the start of every month and the rest earns the expected return, compounded monthly. The balance never goes below zero: when it runs out, the last withdrawal is whatever is left.

InputMeaning
investmentAmount invested at the start.
monthlyWithdrawalAmount withdrawn each month.
annualRateExpected return, % a year.
yearsDuration in years.
ResultMeaning
investmentThe starting amount.
totalWithdrawnEverything actually withdrawn.
finalBalanceWhat's left at the end (0 or more).
returnsfinalBalance + totalWithdrawn − investment.
depletedMonthThe month (from 1) the money ran out, or null.
seriesPoints { year, month, balance, withdrawn }; withdrawn is cumulative.
 
swp( { investment: 100000, monthlyWithdrawal: 10000, annualRate: 10, years: 3 } ).depletedMonth; // 11

goal( inputs )

Time-based goal: what the goal will cost after inflation, and the monthly investment (at the start of each month) needed to reach it on top of the savings already put aside, which keep growing at the expected return. When the savings cover the goal, the monthly investment is 0.

InputMeaning
presentCostWhat the goal costs today.
currentSavingsOptional, default 0: savings already put aside.
inflationRateInflation, % a year.
annualRateExpected return, % a year.
yearsYears until the goal.

Returns { presentCost, futureCost, savingsFutureValue, shortfall, monthlyInvestment, totalInvested, months, series }, plus targetYear when you pass startYear; series points { year, month, goalCost, savings, investments, total }.

const g = goal( { presentCost: 1000000, currentSavings: 100000, inflationRate: 6, annualRate: 9, years: 3 } );
g.futureCost;        // 1191016
g.monthlyInvestment; // 25602 (rounded)

emi( inputs )

Loan EMI (equated monthly instalment) with interest on the reducing balance.

InputMeaning
principalLoan amount.
annualRateInterest, % a year.
yearsTenure in years.

Returns { emi, principal, totalInterest, totalPayment, months, schedule, series }. schedule has one row per loan year (the last may be shorter): { year, principalPaid, interestPaid, balance }. Series points { year, month, balance, principalPaid, interestPaid } are cumulative.

const loan = emi( { principal: 100000, annualRate: 7, years: 1 } );
loan.emi;           // 8652.67…
loan.totalInterest; // 3832.09…

calculate(), types(), register()

types();                                                  // [ 'sip', 'lumpsum', 'swp', 'goal', 'emi' ]
calculate( 'emi', { principal: 100000, annualRate: 7, years: 1 } ); // same as emi( … )
register( 'myCalc', ( inputs ) => ( { /* … */ } ) );       // add or replace a calculator

calculate() throws on an unknown type. Use it when the calculator comes from settings or markup, for example data-calculator="sip".

formatNumber( value, options )

Groups the digits in the Indian or international system.

OptionDefaultMeaning
system'indian''indian' (12,34,567) or 'international' (1,234,567).
decimals0Digits after the decimal point, 0 to 20.
 
formatNumber( 5808477 );                              // "58,08,477"
formatNumber( 5808477, { system: 'international' } ); // "5,808,477"
formatNumber( 1234567.891, { decimals: 2 } );         // "12,34,567.89"

It uses Intl.NumberFormat when the runtime has the en-IN locale, and the same grouping by hand otherwise, so the output never depends on which locales are installed. It never returns "-0".

formatCurrency( value, options )

The currency symbol plus the grouped number. Takes the formatNumber options plus:

OptionDefaultMeaning
symbol'₹'Any text, such as '$' or 'Rs. '.
position'before''before' (₹100) or 'after' (100 €).
 
formatCurrency( -1500 );                                                     // "-₹1,500"
formatCurrency( 1500, { symbol: '€', position: 'after', system: 'international' } ); // "1,500 €"

formatCompact( value, options )

Short form for chart axes and tight spaces: K, L (lakh), Cr (crore) in the Indian system; K, M, B, T internationally. Options: system, and decimals (most digits after the point, default 1).

formatCompact( 1500000 );                              // "15L"
formatCompact( 25000000 );                             // "2.5Cr"
formatCompact( 1500000, { system: 'international' } ); // "1.5M"

amountInWords( value, options )

Spells out an amount, rounded to a whole number, with no size limit: above crore (or decillion) the words repeat. Takes a number, a BigInt, or a string of digits for amounts beyond 253. Option: system.

amountInWords( 2808477 );   // "Twenty Eight Lakh Eight Thousand Four Hundred and Seventy Seven"
amountInWords( 1e12 );      // "One Lakh Crore"
amountInWords( 5808477, { system: 'international' } );
// "Five Million Eight Hundred and Eight Thousand Four Hundred and Seventy Seven"
amountInWords( 0 );         // "Zero"
amountInWords( -1500 );     // "Minus One Thousand Five Hundred"

The words are English unless you pass your own with the words option, for a translation. Add a currency word yourself if you need one ("… rupees").

words keyMeaning
ones20 strings for 0–19 (index 0 is usually '').
tens10 strings: '', '', twenty … ninety.
hundred, and"Hundred" and the word after it ("and"; '' leaves it out).
zero, minusFor 0 and negative amounts.
indian{ thousand, lakh, crore }.
international12 strings: '', thousand, million … decillion.

Missing keys stay English; a list of the wrong length throws a TypeError.

const hindi = {
  ones: [ '', 'एक', 'दो', 'तीन', 'चार', 'पाँच', 'छह', 'सात', 'आठ', 'नौ', 'दस',
          'ग्यारह', 'बारह', 'तेरह', 'चौदह', 'पंद्रह', 'सोलह', 'सत्रह', 'अठारह', 'उन्नीस' ],
  tens: [ '', '', 'बीस', 'तीस', 'चालीस', 'पचास', 'साठ', 'सत्तर', 'अस्सी', 'नब्बे' ],
  hundred: 'सौ', and: '', zero: 'शून्य', minus: 'ऋण',
  indian: { thousand: 'हज़ार', lakh: 'लाख', crore: 'करोड़' },
};
amountInWords( 150000, { words: hindi } ); // "एक लाख पचास हज़ार"

groupDigits( digits, system ), VERSION

groupDigits( '1234567' ) returns "12,34,567": the hand-made grouping formatNumber falls back to, for a string of digits. VERSION is the library version, such as "1.0.0".

TypeScript

Types ship with the package (types/financial-calculators.d.ts): every input and result interface, plus calculate() typed by calculator name, and window.FinancialCalculators for the browser build.

import { emi, type EmiResult } from '@wpgenius/financial-calculators';
const loan: EmiResult = emi( { principal: 100000, annualRate: 7, years: 1 } );

Formulas

CalculatorFormula (i = monthly rate, n = months)
SIPP × ((1 + i)^n − 1) / i × (1 + i) (investment at the start of each month)
Lump sumP × (1 + r / k)^(k × years), k = compounding per year
SWPEach month: withdraw, then the rest grows by i; stops at zero.
GoalFuture cost C × (1 + inflation)^years; savings grow yearly; the gap is divided by the SIP factor.
EMIP × i × (1 + i)^n / ((1 + i)^n − 1); at 0%, P / n.

The unit tests check each formula against reference values. Found a result that looks wrong? Report it with the inputs and the value you expected.
