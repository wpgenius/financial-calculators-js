How it works

Plain functions, plain numbers

No classes, no state, no DOM. You pass inputs, you get numbers back, and you decide how to show them.

  1. Call a calculator

    sip(), lumpsum(), swp(), goal() or emi() with one object of inputs. Rates are % a year; years may have fractions.

  2. Get totals and a series

    Every result has its totals plus a series with one point per year, ready for a line or bar chart. EMI adds a yearly repayment schedule.

  3. Format for people

    formatCurrency(), formatCompact() for chart axes, and amountInWords() in the Indian or international system.

Features

What's inside

Five calculators

SIP, lump sum (yearly, quarterly or monthly compounding), SWP, time-based goal and loan EMI.

Honest edge cases

SWP stops at zero and reports the month the money runs out; a goal already covered by savings needs nothing more each month; 0% rates work.

Chart-ready series

One point per year plus the final month, with invested, total, balance or cumulative interest, depending on the calculator.

Indian and international

12,34,567 or 1,234,567; 15L and 2.5Cr or 1.5M; lakh and crore or million and billion.

Amounts in words

"Twenty Eight Lakh Eight Thousand Four Hundred and Seventy Seven", with no size limit (BigInt and digit strings too).

Small and typed

No dependencies, about 3 KB gzipped, TypeScript types included, and unit tests with reference values.

Get started

Install

Use a <script> tag (the global FinancialCalculators), or import it as an ES module.

<script src="https://cdn.jsdelivr.net/npm/@wpgenius/financial-calculators@1/dist/financial-calculators.min.js"></script>
<script>
  const { sip, formatCurrency, amountInWords } = FinancialCalculators;
  const result = sip( { monthlyAmount: 25000, annualRate: 12, years: 10 } );
  formatCurrency( result.total );  // "₹58,08,477"
  amountInWords( result.total );   // "Fifty Eight Lakh Eight Thousand Four Hundred and Seventy Seven"
</script>

@1 follows the latest 1.x release; pin an exact version (such as @1.0.0) in production.

npm install @wpgenius/financial-calculators
import { emi, formatCurrency } from '@wpgenius/financial-calculators';

const loan = emi( { principal: 3000000, annualRate: 8.5, years: 20 } );
formatCurrency( loan.emi );  // "₹26,035"
loan.schedule[ 0 ];          // { year: 1, principalPaid, interestPaid, balance }

Each release has three files: financial-calculators.min.js (for a <script> tag), the readable financial-calculators.js, and financial-calculators.esm.js for import.

<script src="financial-calculators.min.js"></script>
